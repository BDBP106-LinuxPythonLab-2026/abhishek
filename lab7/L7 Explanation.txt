2.1) touch newfile
     ls -l newfile
     Output:- 
       -rw-rw-r-- 1 ibab ibab 0 Aug  6 16:29 newfile
EXPLANATION:- 
A new empty file is created.
Owner: Read & Write (rw-)
Group: Read & Write (rw-)
Others: Read only (r--)
Permission = 664

2.2) umask
Output:- 0002
EXPANATION:- umask sets default permissions.
Default file permission = 664
Default directory permission = 775

2.3) touch Newfile
     ls -l Newfile
Output:- -rw-rw-r-- 1 ibab ibab 0 Aug  6 16:39 Newfile
EXPLANATION:- A new file is created.
Permission is 664 because the umask is 0002.

2.4) mkdir newdir
     ls -ld newdir
     Output:- drwxrwxr-x 2 ibab ibab 4096 Aug  6 16:46 newdir
EXPLANATION:- A new directory is created.
Owner: rwx
Group: rwx
Others: r-x
Octal permission = 775

2.5) cp -r Newfile newdir/
     ls -l newdir/Newfile
Output:- -rw-rw-r-- 1 ibab ibab 0 Aug  6 16:59 newdir/Newfile
EXPLANATION:- The file is copied successfully.
The copied file has the same permission (664).
Copying does not change file permissions.

2.7) mkdir newdir
     mv file1 newdir
     cd newdir
     ls
Output:-      Newfile  Newfile1  file1
     ls -al file1
Output:- -rw-rw-r-- 1 ibab ibab 0 Aug  6 17:06 file1
EXPLANATION:- The file is moved to newdir.
Moving a file does not change its permissions.
Only the file location changes.
